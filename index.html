02. philosophy

Everything fundamentally starts with a dot. To solve the old age question of shapes, polygons, lines, or simply drawn elements being baked straight into static pixels, dot.js uses a reference architecture.

Every shape or line drawn on the canvas is given a reference to allow properties to be changed later. This was made to increase control of elements made.

03. cheatsheet for beginners

Initialize your canvas and assign persistent references for O(1) lookups:

// Include via CDN
<script src="https://stevenpitso.github.io/DotJS/dist/dotjs.min.js"></script>
<script>
  // Initialize state-driven canvas
  const app = createCanvas({
    use: '#canvas',
    background: '#ffffff'
  });

  // Create shape and register reference
  circle(400, 300, 80)
    .fill('#84cc16')
    .setRef('myDot');

  // Modify properties later without clearing canvas
  app.draw(() => {
    const dot = useRef('myDot');
    if (dot) dot.rotate(0.02);
  });
</script>
