dot.js

State-managed graphics library for HTML Canvas.

Quick Start

Once installed, initialize your canvas and start drawing with the global context.(pending for future updates and testing)

import { dot } from 'dotjs-core';
dot.init('#myCanvas');

Installation

Simply include the distributed script in your project or install via npm.

Core Philosophy

Dot.js moves away from "fire-and-forget" canvas rendering. By maintaining a persistent Reference Registry, you can manipulate any shape or polygon long after it has been drawn to the screen.

Examples

1. Basic Shape Declaration

const box = rect(50, 50, 100, 100)
  .fill("#6FFF00")
  .setRef("hero-box");

2. Remote Manipulation

useRef("hero-box")
  .rotate(0.5)
  .move(200, 200);
